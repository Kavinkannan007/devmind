# Security and data handling

DevMind indexes public GitHub repositories. Imported files are parsed as data in memory. The importer does not clone, install dependencies, run scripts, invoke shells, write imported paths to disk or grant the model tools. Redirects are disabled and requests use constructed GitHub API paths. Git modes, path components, file extensions, control characters, generated lines and configured sizes determine eligibility.

Supabase validates bearer tokens. FastAPI derives the owner from the verified identity and checks ownership before each repository read, write or AI operation. Browser roles have no access to the private database schema. Tables also have RLS enabled. Keep database credentials and all provider tokens server-side. Only the Supabase project URL, publishable key and API base URL belong in Vite variables.

The worker filters common credential files and redacts likely tokens, connection strings, private keys and assignments. Pattern detection cannot recognize every secret. Only import material you are permitted to send to Google. GitHub receives repository requests. Gemini receives redacted snippets for embeddings, questions, bounded chat history and selected excerpts for generation. Provider-side retention follows the provider's current agreement and account settings. [Gemini terms](https://ai.google.dev/gemini-api/terms)

DevMind retains indexed content, embeddings, metadata, generated documents and chat excerpts in Supabase until repository or account deletion. Repository deletion cascades through local index data and history. Account deletion in Supabase cascades through the workspace. Quota counters are account-scoped. Backup retention is controlled by the database provider. Production logging should exclude request bodies, bearer headers, database URLs and source text.

Treat answers and imported Markdown as untrusted. The application uses structured evidence IDs, caps context and output, and renders model responses through React Markdown. The assistant has no repository write access. Pagination/size caps, provider retries, fixed-origin CORS, per-minute operation limits, per-user daily quotas and globally bounded import workers constrain costs. Provider rejection can still consume a reserved daily operation. Control account creation and monitor provider-side budgets before opening registration broadly.
