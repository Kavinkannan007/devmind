# First-week delivery plan

| Window | Outcome | Acceptance |
| --- | --- | --- |
| First working session | Local import-to-answer implementation and testable deployment configuration | Real GitHub ingestion, SQL verification, frontend build, retryable jobs and live acceptance tests available |
| Day 2 | Connected hosted services | Two authenticated imports produce Gemini vectors and cited answers in Supabase |
| Day 3 | Explorer and search review | Citation clicks, old-commit links and saved sessions verified in a real account |
| Day 4 | Architecture and impact review | Cross-check dependency edges and traversal against both imported snapshots |
| Day 5 | Operational testing | Native PostgreSQL concurrent jobs, interruption, retry, budgets and account isolation verified |
| Day 6 | Deployment review | Confirm private GitHub destination, review staging config, data handling and rendered responsive pages |
| Day 7 | Approved release | Verify deployed URLs and repeat live acceptance tests, then record remaining limitations |

The schedule depends on external service configuration, quota availability and publication approval. See PROGRESS.md for observed results.
